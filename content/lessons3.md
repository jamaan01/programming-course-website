# Типи даних у Go

Go — це мова програмування зі **статичною типізацією**.  
Це означає, що кожна змінна має певний тип, і після створення цей тип змінити не можна.

Іноді через це програма може не компілюватися, якщо типи не збігаються. Але в цьому є велика перевага: **багато помилок знаходяться ще до запуску програми**. Це допомагає уникнути проблем у роботі програми.

У Go є кілька основних типів даних, з якими ми будемо працювати найчастіше:

- числа
- рядки
- логічні значення

## Числа

Для роботи з числами в Go існує два основних типи:

- **цілі числа**
- **числа з дробовою частиною**

## Цілі числа

Цілі числа — це числа **без дробової частини**.

Наприклад: 1, 10, 500, -25, 0

У Go існує кілька типів цілих чисел.

## Знакові числа

Вони можуть бути як **додатними, так і від’ємними**.

| Тип   | Розмір  | Діапазон                 |
| ----- | ------- | ------------------------ |
| int8  | 8 біт   | -128 … 127               |
| int16 | 16 біт  | -32768 … 32767           |
| int32 | 32 біти | -2147483648 … 2147483647 |
| int64 | 64 біти | дуже великі числа        |

Число в назві означає **кількість біт**, які використовуються для зберігання числа.

Чим більше біт — тим **більше число можна зберігати**.

## Беззнакові числа

Такі числа можуть бути **тільки додатними або нулем**.

| Тип    | Діапазон          |
| ------ | ----------------- |
| uint8  | 0 … 255           |
| uint16 | 0 … 65535         |
| uint32 | 0 … 4294967295    |
| uint64 | дуже великі числа |

## Який тип використовувати?

У більшості програм достатньо використовувати просто:

int

Це стандартний тип для цілих чисел у Go.

Приклад:

```go
package main

import "fmt"

func main() {
    var age int = 25
    fmt.Println(age)
}
```

## Числа з дробовою частиною

Числа з дробовою частиною називають числами з плаваючою точкою.

Наприклад: 1.5, 10.25, 0.75

У Go є два типи для таких чисел:

-float32
-float64

float32 — займає 32 біти

float64 — займає 64 біти і має більшу точність

У більшості випадків використовують float64.

Приклад:

```go
package main

import "fmt"

func main() {
    var price float64 = 19.99
    fmt.Println(price)
}
```

## Рядки (string)

Рядок — це тип даних, який використовується для роботи з текстом.

Приклади рядків:

-"Hello"
-"Go"
-"Programming"

Приклад використання:

```go
package main

import "fmt"

func main() {
    var message string = "Hello Go"
    fmt.Println(message)
}
```

Об'єднання рядків

Рядки можна об'єднувати за допомогою +.

```go
fmt.Println("Hello " + "Go")
```

Результат:

_Hello Go_
Довжина рядка

Можна дізнатися довжину тексту за допомогою функції len.

```go
fmt.Println(len("Hello"))
```

Доступ до символів у рядку

У Go можна звертатися до окремих символів рядка.

Кожен символ має свій номер (індекс), і нумерація починається з 0.

Наприклад, у слові "Hello":

H e l l o
0 1 2 3 4

Можна звернутися до конкретного символу:

```go
package main

import "fmt"

func main() {
fmt.Println("Hello"[1])
}
```

Поки що ми не будемо активно використовувати цей спосіб.
Пізніше в курсі ми детальніше розглянемо, як працюють рядки всередині Go і навіщо може знадобитися доступ до окремих символів.

Зараз достатньо просто знати, що така можливість існує.

## Логічний тип

У Go є логічний тип:

bool

Він може мати лише два значення:

true
false

Такий тип використовується тоді, коли потрібно отримати відповідь «так» або «ні», «правда» або «неправда».

Наприклад, уявімо просту ситуацію.
У вас є число 32. Хтось підходить до вас і запитує:

“Це число 32?”

Якщо це справді 32, ви відповідаєте:

true

Тобто так, це правда.

Якщо ж число інше, наприклад 25, то відповідь буде:

false

Тобто ні, це неправда.

Саме для таких перевірок і використовується тип bool.

Логічні оператори

У Go існує кілька логічних операторів. Вони використовуються для того, щоб поєднувати або змінювати перевірки.

| Оператор | Значення |
| -------- | -------- |
| `&& `    | І        |
| `\|\|`   | АБО      |
| `! `     | НЕ       |

Оператор І (&&)

Цей оператор означає, що обидві умови повинні бути правдивими.

Наприклад:

Уявімо, що людина може отримати доступ до системи тільки якщо:

їй більше 18 років

і вона зареєстрована

Якщо обидві умови виконуються, результат буде true.
Якщо хоча б одна з них не виконується — результат буде false.

Оператор АБО (||)

Цей оператор означає, що достатньо виконання хоча б однієї умови.

Наприклад:

Людина може отримати знижку якщо вона:

студент

або пенсіонер

Якщо хоча б одна з цих умов виконується — результат буде true.

Оператор НЕ (!)

Цей оператор перевертає значення.

true стає false

false стає true

Наприклад:

Якщо у вас є перевірка:

“користувач авторизований”

то оператор ! означатиме:

“користувач не авторизований”.

Пізніше в курсі, коли ми почнемо працювати з умовами у програмах, ми детальніше розглянемо ці оператори на практичних прикладах.
