# Перша програма на Go — «Hello, Go!»

Традиційно перша програма, з якої починається вивчення будь-якої мови програмування, називається «Hello World». Вона просто виводить у консоль відповідний текст.
Ми трохи змінимо класичний варіант і напишемо програму, яка виведе:
Hello, Go!

Ось як виглядає наша перша програма:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

## Розберімося, що тут відбувається

`package main`

Ми оголошуємо пакет із назвою main.

У будь-якій програмі, яку можна запустити, обов’язково має бути пакет main. Саме з нього починається виконання програми.

Детальніше про пакети поговоримо в окремому модулі — поки що достатньо розуміти, що це точка входу в програму.

Порожній рядок

Go не звертає уваги на порожні рядки.
Ми використовуємо їх для зручності читання коду.

Можете видалити цей рядок — програма працюватиме так само.

`import "fmt"`

Тут ми підключаємо пакет fmt.

Пакет fmt відповідає за введення та виведення даних.
Зараз він потрібен нам для виведення тексту в консоль.

`func main() {}`

Ми оголошуємо функцію з назвою main.

Назва main є спеціальною — саме ця функція автоматично викликається під час запуску програми.

Якщо у програмі немає функції main, її неможливо запустити.

`fmt.Println("Hello, Go!")`

Тут відбувається головне — виведення тексту.

- fmt — це підключений нами пакет

- Println() — функція з цього пакета

- "Hello, Go!" — текст, який ми хочемо вивести

Println виводить текст і автоматично переходить на новий рядок.

## Практика

Тепер спробуйте змінити програму самостійно.

Завдання 1

Напишіть програму, яка виводить:

```text
I like Go!
```

Завдання 2

Напишіть програму, яка виведе:

```text
Go is cool!
```

Завдання 3 (трохи складніше)

Напишіть програму, яка виведе:

```text
Hello, Go!
I like Go!
Go is powerful!
```
